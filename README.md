# Chakra Charge Mod

A Minecraft mod that adds a custom item called Chakra Charge, which grants speed and visual effects when held.

## Features

- Adds a custom Chakra Charge item with a glowing blue orb texture.
- Grants speed and visual effects when the item is held.

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.15.7 or later
- Fabric API

## Installation

1. Download the mod JAR file.
2. Place the JAR file in your Minecraft mods folder.
3. Launch Minecraft with the Fabric profile.

## Usage

1. Obtain the Chakra Charge item in-game.
2. Hold the item to activate speed and visual effects.

## Configuration

No additional configuration is required.
